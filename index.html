Current lab setup

Learning with real tools in a virtual environment.

⌘

Oracle VirtualBox

Virtual machines provide a safe place to build, test, document, and reset lab scenarios.

▣

Windows 11 client

A Windows 11 workstation is used for domain joining, user troubleshooting, policy testing, and help desk practice.

↗

Windows Server 2025

The server environment supports Active Directory, identity and access management, DNS, and administrative practice.

↔

RustDesk remote access

RustDesk and Tailscale support controlled remote access while keeping the lab separated from the host system.

A practical path

Learn. Practice. Document. Explain.

  1. 01

    Learn the concept

    Start with the Windows, networking, identity, or security principle behind the task.

  2. 02

    Work the scenario

    Apply the concept in a lab environment with a realistic user or system problem.

  3. 03

    Record the evidence

    Capture what changed, what you tested, and how you would communicate the result.

  4. 04

    Explain the decision

    Practice describing your troubleshooting process in plain language.
